Project 01 · E-commerce app

BooksBay

A marketplace to buy, sell and discover books. Readers browse by category, read a description, add to cart and check out. They can also list their own books by uploading a photo.

Buy

Search for a title, open the book page, read the description and add it to the cart. The cart shows quantity, a coupon field, subtotal, delivery fee and total.

Sell

A dedicated Sell screen lets readers upload from the gallery or take a photo, then see their listings next to popular books.

Check out

Delivery address with a Change option, three payment methods (UPI, card, cash on delivery) and a clear Order Placed confirmation with the delivery window.

Project 02 · Fintech onboarding

Infinity Banking

The entry flow for a mobile bank: splash, Mpin login, account sign up and one-time password check. Large inputs, a single action per screen and a calm green palette keep a sensitive task easy.

Login

A 6-digit Mpin field with a show/hide toggle, one primary button and a Sign up link for new customers.

Sign up

Email, first name, account number, password and confirm password, with underlined fields and one Next button.

OTP

A 4-digit code sent to the customer's phone, with a 30 second resend timer and a Confirm button.

Project 03 · Website design

M&M'S Haunted Candy World

A Halloween landing page concept. A full-screen scene of the characters opens the page, followed by sections for products, characters, seasonal treats and where to buy. Purple night tones and orange highlights set the mood.

Concept work for portfolio use, not an official page.

Hero

One headline, one line of copy and one button over the full scene, so the page makes its point before any scrolling.

Sections

Products, Characters, Halloween, Recipes, Where to Buy and a footer, matching the navigation so every link lands on a clear section.

Palette

Deep purple for night, orange for actions and green for small accents.
